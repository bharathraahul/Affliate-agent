## What each sponsor does (for picking tracks)

- **Guild.ai** — agent framework / orchestration. Fits the autonomous-agent core.
- **Truefoundry** — ML/LLM deployment & serving platform.
- **Pioneer** — inference platform (Pro plan = $1500 inference credits). Good for running the LLM cheaply.
- **OpenUI** — generate UIs from descriptions. Fits the landing page / professional website question.
- **ClickHouse** — analytics database. Fits storing leads, ad performance, conversation analytics.
- **Langfuse** — LLM observability/tracing. Easy add-on for any LLM app.
- **Render** — cloud hosting/deploy. Fits "keep running after hackathon."
- **Airbyte** — data integration / agent engine (context pipelines). Could feed lead/business data.
- **Composio** — agent tool/action execution (integrations for agents to take actions).
- **Senso.ai** — (verify) knowledge/context for agents.

## Recommended fit for our idea (personal shopper lead-gen)

Strong matches:
- **Guild.ai** — core agent that talks to leads. (High-value $2,800 track.)
- **OpenUI** — build the landing page / professional front-end quickly.
- **Render** — deploy so it keeps running post-hackathon (aligns with our goal).
- **ClickHouse** — lead + ad-performance analytics (natural data layer).
- **Composio** — agent takes real actions (send affiliate links, contact businesses, post ads).
- **Langfuse** — cheap observability bolt-on; easy 4th/5th track.

Easiest path to 3+: **Guild.ai + OpenUI + Render** (core + UI + deploy), then add **Langfuse** and **ClickHouse** as low-effort bonus tracks.
